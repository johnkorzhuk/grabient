# فارسی (fa)

How Persian says Grabient's own words. Read `README.md` for what each word means here; use the word below every time,
and add a row when a new product word gets its translation. Persian reads right to left; the page mirrors itself
(docs/i18n.md), so a translation never needs bidi control characters.

Color names (`colornames.data.ts`) are whole phrases, one message each: قرمز، نارنجی، زرد، سبز، کله‌غازی (teal)، آبی،
سرمه‌ای (navy)، بنفش، صورتی، سیاه، سفید، خاکستری; dark and light follow the hue: آبی تیره، آبی روشن. Two ends are
`{start} تا {end}` (زرد کم‌رنگ تا صورتی), and a name follows its noun: پالت {name}، گرادیان {name}.

The palette search knows Persian words, so its examples are Persian.

Names of formats and standards stay as they are, in Latin script: OKLCH, OKLab, sRGB, Display P3, CSS, SVG, PNG, JPG,
WebP, JSON, GLSL, WGSL, Shadertoy, Figma, MCP, URL, Markdown, JavaScript, and the companies (Google, Cloudflare,
Resend).

## How Persian writes here

- Formal register, as Iranian software writes: the plural imperative (`دوباره تلاش کنید`, `وارد شوید`), never the
  familiar singular. Buttons, tabs and chips are a verbal noun or a noun (`ذخیره`, `افزودن کی‌فریم`, `کپی`), as short as
  the English.
- The zero-width non-joiner (نیم‌فاصله, U+200C) in every compound and prefix: می‌شود، نمی‌توان، پالت‌ها، ذخیره‌شده،
  پیش‌نمایش، به‌عنوان. Never a space, never glued.
- Persian yeh and kaf (ی ک), never the Arabic ي ك.
- Persian punctuation: ، ؛ ؟ and « » for quotes. No em dashes: a colon or
  a comma instead. The page titles keep the product's own `Grabient — …` form.
- Numbers stay in Western digits as the app writes them, in the text too (`5 دقیقه`, `256 × 256`); the runtime writes
  counts the same way. They match the sliders, sizes, hex codes and code shown next to the text.
- The ezafe after a silent heh is not written (`اندازه پیش‌نمایش`, not `اندازهٔ`), as Iranian interfaces write it.
- An arrow that means "from … to" in running text is words (`از 0.86 به 0.32`): a → does not turn in a right-to-left
  line. Arrows inside code (`<c>…</c>`) stay as they are. "Open →" is `باز کردن ←`, "↗" is `↖`.
- Don't end a Persian sentence with a Latin word followed by brackets: write `oklch`, not `oklch()`.
- The code isolates every value set into a sentence (a hex code, a size, a name), so a value displays in its own direction and translators need not reorder it.
- No bidi control characters: the page and the design system isolate what reads left to right.
