# Korean (ko)

The product's words in Korean, as Korean designers meet them in Figma, Adobe and on the web. Use these every time.

## Palette names

A palette's generated name is its two ends joined by a hyphen, the Korean mark for a run of things in order:
"Light yellow to pink" is 연노랑-분홍 ("{start}-{end}"). The name then takes a noun directly (연노랑-분홍 팔레트,
연노랑-분홍 선형 그라데이션) and only particles that do not change with the last sound (에, 의).

The colors are the crayon names, each one word: 검정, 흰색, 회색, 빨강, 주황, 노랑, 초록, 청록, 파랑, 남색, 보라, 분홍.
Light is 연- and dark is 진-: 연노랑, 진파랑, 연회색, 진회색. The classifier's Ramp is 램프 and Pastel is 파스텔.

## How Korean writes here

- Sentences are 해요체 everywhere: -아요/-어요 for statements (저장했어요, 불러오지 못했어요),
  -세요 for a request (선택하세요), -해 주세요 for please (다시 시도해 주세요). The About page, the emails, the
  contact page and the English-only notice ("This page is in English only.") are 해요체 too.
- Buttons, tabs, chips and menu items are nouns or noun phrases: 복사, 다운로드, 저장, 내보내기, 팔레트 삭제, 다시 시도.
  Tooltips name the action as noun phrases, like the buttons (선택 항목에 추가), then the key.
- A label that acts on everything puts 모두 right before the verb: 선택 항목에 모두 추가. At the start of a label,
  모두 선택 reads as Select all.
- Something under way: 저장하는 중…, 검색 중…, 더 불러오는 중….
- A failure: ~하지 못했어요, and Try again is always 다시 시도해 주세요. A missing thing: 찾을 수 없어요.
  Invalid: 올바르지 않은 이미지예요, but 잘못된 요청이에요 and 유효하지 않은 링크예요.
- A count is noun then number with 개: 팔레트 12개, 색상 7개. A stat that sets the number in its own type puts the
  word first: 팔레트 12. Selected: 3개 선택됨.
- A card's age says 전: 5분 전, 3시간 전, 2일 전, 4개월 전.
- Ranges use the tilde: 1~80자, 2~8개.
- No particle directly after a value whose last sound is unknown ({title}, {key}, {tags}): add a noun that carries it
  ({key} 키는), or use one that does not change (에, 에서, 까지, 의).
- Korean has one plural form: write `{count, plural, other {팔레트 #개}}`.
- The search words of the free search are English, so the examples in search hints stay English
  (navy, cozy, sunset).
- Formats, standards and names stay as they are: OKLCH, OKLab, sRGB, CSS, SVG, PNG, JSON, hex, Figma, Google.
- A parenthesis sits against the word before it: 이유(선택), {name}(에이전트), RGB(위).
- No em dashes except the home page title, which carries the brand's own "Grabient —".
