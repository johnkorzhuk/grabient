## Generated color names

Hyphenated compounds, as the orthography writes them: preto, branco, cinza, cinza-escuro, vermelho, laranja, amarelo,
verde, turquesa (teal), azul, roxo, rosa; dark and light are -escuro and -claro ("azul-escuro", "rosa-claro"). "{start}
to {end}" is "{start} para {end}" ("Amarelo-claro para rosa"), the way Brazilians name a gradient ("degradê de azul para
rosa"). The code capitalizes the first letter of a name, so the templates put the name first: "{name}: {style}",
"{name}: paleta com 7 cores".

## Register

- Address the reader as "você". Sentence case. Plain, short, no exclamation marks, no em dashes.
- Buttons are infinitives ("Salvar", "Copiar URL", "Excluir conta"). Tooltips are the press's name, as on its
  button, then its key: "Inverter · I".
- Failures: "Não foi possível salvar a paleta." Retry: "Tente novamente."
- "Press" on a control is "Clique"; on a key it is "Pressione". A control named inside a sentence takes curly quotes:
  "clica de novo em “Em ascensão”".
- Decimals in prose take a comma (0,86) and thousands a point (5.000); a unit stands apart ("5 MB"). Numbers the code
  writes stay as the code writes them.
- Titles and descriptions use what Brazilian searchers type: "gerador de gradiente", "gradiente CSS", "paleta de cores".
- Search headings that carry the query use a colon, not "para": "Paletas salvas: {query}", "Suas coleções: {query}",
  matching "{subject}: gradientes e paletas de cores". A search by a palette says "parecidas com": "Paletas parecidas
  com {name}"; Similar palettes is "Paletas parecidas" and Matching collections "Coleções correspondentes".
- "Termos de Serviço" and "Política de Privacidade" keep their capitals as the documents' names.

## Plurals

pt-BR has one (0 and 1), many (whole millions: "1.000.000 de paletas") and other. Every plural gives all three. Where a
count can be 0 on screen (results, selected, palettes in a list), the message also has `=0`, so it reads "0 paletas"
rather than CLDR's "0 paleta".
