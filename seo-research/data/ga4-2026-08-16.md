The decisive reconciliation with Search Console: GSC shows **zero clicks** to any
color page, yet GA4 shows thousands of views. Those views are **internal
navigation** — people arriving on `/` and clicking the suggestion chips. So the
color pages are genuinely useful to visitors and genuinely invisible to Google.
That is precisely the gap the sitemap expansion and the "gradient" retitle
address, and it is now measured rather than assumed.

`/palettes/green` earning 900 views while absent from the sitemap is the single
clearest argument for the 20-color expansion.

Two seed permalinks appear in the top 10 (~1,200 views, ~335 users each), which
also argues against the earlier proposal to noindex the seed corpus.

## Method

Data API v1beta, `runReport` with the same JWT flow as Search Console. The
service account needs Viewer on the GA4 property and the Data API enabled on
Google Cloud project 453530220316 (both done 2026-08-16).
