Grabient background

This page sits on a rosette.

The background is a Grabient palette playing as a rosette, petals on a golden spiral whose rings of color ripple out from the heart, softened and grained. Two tags in the head put it there.

<style>
html::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/svg+xml,%3Csvg xmlns…") 50% 50% / cover no-repeat;
  filter: blur(0.457vmax);
}
html::after {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -2;
  pointer-events: none;
  background: linear-gradient(90deg, #000107 0%, #000739 13.364%, #000b3d 14.506%, #315f73 28.555%, #b5b58c 42.718%, #bdb98a 44.089%, #face6b 56.082%, #fecf67 57.143%, #ffcc63 58.138%, #f29d34 70.473%, #ed962e 71.844%, #893700 85.714%, #0a0000 99.028%, #050000 100%);
}
body::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/png;base64,iVBORw0K…") 0 0 / 128px 128px;
  image-rendering: pixelated;
}
html[data-grabient-playing]::before {
  background: none;
  filter: none;
}
html[data-grabient-playing]::after,
html[data-grabient-playing] body::before {
  background: none;
}
</style>
<script src="https://staging.grabient.com/kcERi8Fyy_zqWO_hlTGb7C9OA3va4rz2CA29A.js?style=rosette&amp;soft=20&amp;grain=20" async></script>

The style holds the first frame, so the page paints it at once and waits on no other site. The script plays the motion on WebGL from that frame. Without WebGL, or for a reader who asks for less motion, the first frame stays. Leave the page's own background off, or set it on html only. The style paints on html::before, html::after and body::before, the gradient under the soft on the second and the grain on the third, so the page's own CSS leaves those to it.

In the editor, Copy HTML gives these two tags for any palette. To link a stylesheet instead of pasting the style, <link rel="stylesheet" href="https://staging.grabient.com/kcERi8Fyy_zqWO_hlTGb7C9OA3va4rz2CA29A.css?style=rosette&amp;soft=20&amp;grain=20"> paints the same frame, but the page then waits for it before it paints.
