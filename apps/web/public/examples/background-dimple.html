Grabient background

This page sits on a dimple.

The background is a Grabient palette drawn as a dimple, a sheet of round scales pressed in at one point, its colors running out from the hollow. Move the pointer: the hollow follows it and stays where you leave it. Two tags in the head put it there.

<style>
html::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/svg+xml,%3Csvg xmlns…") 50% 50% / cover no-repeat;
}
html[data-grabient-playing]::before {
  background: none;
}
</style>
<script src="https://staging.grabient.com/kYNh-6rw818GUvVJB75wwtTjQcvy.js?style=dimple" async></script>

The style holds its still, the hollow at its rest, so the page paints it at once and waits on no other site: a plain SVG of circles, each filled by one gradient that is the palette. The script then has the hollow follow the pointer, on WebGL, and draws nothing while the pointer is still: nothing in it moves by itself. Without WebGL, or for a reader who asks for less motion, the still stays. Leave the page's own background off, or set it on html only. The style paints on html::before, so the page's own CSS leaves that to it.

In the editor, Copy HTML gives these two tags for any palette. To link a stylesheet instead of pasting the style, <link rel="stylesheet" href="https://staging.grabient.com/kYNh-6rw818GUvVJB75wwtTjQcvy.css?style=dimple"> paints the same still, but the page then waits for it before it paints.
