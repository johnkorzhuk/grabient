Grabient background

This page sits on fluted glass.

The background is a Grabient palette playing as fluted glass. Two tags in the head put it there.

<style>
html::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/webp;base64,UklGRlJMAABX…") 50% 50%/cover no-repeat;
}
</style>
<script src="https://staging.grabient.com/kWnCIwwC47igfOklkTlShq44.js?style=glass&amp;angle=135&amp;speed=2.45" async></script>

The style holds the first frame, so the page paints it at once and waits on no other site. The script plays the motion on WebGL from that frame. Without WebGL, or for a reader who asks for less motion, the first frame stays. Leave the page's own background off, or set it on html only.

In the editor, Copy HTML gives these two tags for any palette. To link a stylesheet instead of pasting the style, <link rel="stylesheet" href="https://staging.grabient.com/kWnCIwwC47igfOklkTlShq44.css?style=glass&amp;angle=135&amp;speed=2.45"> paints the same frame, but the page then waits for it before it paints.
