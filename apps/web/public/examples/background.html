Grabient background

This page sits on fluted glass.

The background is a Grabient palette playing as fluted glass. Two tags in the head put it there.

<link rel="stylesheet" href="https://staging.grabient.com/kWnCIwwC47igfOklkTlShq44.css?style=glass&angle=135&speed=2.45">
<script src="https://staging.grabient.com/kWnCIwwC47igfOklkTlShq44.js?style=glass&angle=135&speed=2.45" async></script>

The stylesheet paints the first frame, so the page never shows without it. The script plays the motion on WebGL from that frame. Without WebGL, or for a reader who asks for less motion, the first frame stays. Leave the page's own background off, or set it on html only.

In the editor, Copy HTML gives these tags with the first frame inside your page instead of the stylesheet link, so your page waits on no other site to paint.
