Grabient background

This page sits on papercut.

The background is a Grabient palette playing as papercut, its colors cut into sheets of paper stacked into a relief that drifts and breathes, each sheet casting a soft shadow on the one below, with film grain over it. Two tags in the head put it there.

<style>
html::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/svg+xml,%3Csvg xmlns…") 50% 50% / cover no-repeat;
}
body::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/png;base64,iVBORw0K…") 0 0 / 128px 128px;
  image-rendering: pixelated;
}
html[data-grabient-playing]::before {
  background: none;
}
html[data-grabient-playing] body::before {
  background: none;
}
</style>
<script src="https://staging.grabient.com/kWvGMX0r8_ce_v26ML9Lx8-w.js?style=papercut&amp;grain=20" async></script>

The style holds the first frame, so the page paints it at once and waits on no other site: a plain SVG of the cut sheets, their shadows drawn in steps. The script plays the motion on WebGL from that frame, its shadows soft as it fades in. Without WebGL the first frame stays, and for a reader who asks for less motion the script holds its own, its shadows soft. Leave the page's own background off, or set it on html only. The style paints on html::before and body::before, the grain on the second, so the page's own CSS leaves those to it.

In the editor, Copy HTML gives these two tags for any palette. To link a stylesheet instead of pasting the style, <link rel="stylesheet" href="https://staging.grabient.com/kWvGMX0r8_ce_v26ML9Lx8-w.css?style=papercut&amp;grain=20"> paints the same frame, but the page then waits for it before it paints.
