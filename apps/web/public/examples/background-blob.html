Grabient background

This page sits on a blob.

The background is a Grabient palette playing as three blobs filling the window. Two tags in the head put it there.

<link rel="stylesheet" href="https://staging.grabient.com/kWTATrcQ7MeMxv1MwbbLKq84.css?style=blob&fill=1&bg=deep">
<script src="https://staging.grabient.com/kWTATrcQ7MeMxv1MwbbLKq84.js?style=blob&fill=1&bg=deep" async></script>

The stylesheet paints the first frame, so the page never shows without it. The script plays the motion on WebGL from that frame. Without WebGL, or for a reader who asks for less motion, the first frame stays. Leave the page's own background off, or set it on html only.
