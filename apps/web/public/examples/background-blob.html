Grabient background

This page sits on a blob.

The background is a Grabient palette playing as three blobs filling the window. Two tags in the head put it there.

<style>
html::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/svg+xml,%3Csvg xmlns…") 50% 50% / 100% 100% no-repeat #151315;
}
html[data-grabient-playing]::before {
  background: none;
}
</style>
<script src="https://staging.grabient.com/kWTATrcQ7MeMxv1MwbbLKq84.js?style=blob&amp;shape=51&amp;bg=%23151315" async></script>

The style holds the first frame, so the page paints it at once and waits on no other site. The script plays the motion on WebGL from that frame. Without WebGL, or for a reader who asks for less motion, the first frame stays. Leave the page's own background off, or set it on html only.

In the editor, Copy HTML gives these two tags for any palette. To link a stylesheet instead of pasting the style, <link rel="stylesheet" href="https://staging.grabient.com/kWTATrcQ7MeMxv1MwbbLKq84.css?style=blob&amp;shape=51&amp;bg=%23151315"> paints the same frame, but the page then waits for it before it paints.
