Grabient background

This page sits on a zen garden.

The background is a Grabient palette playing as a zen garden, sand raked in its colors round a group of stones, the rings round them swelling and drawing back while the raked lines drift slowly, with film grain over it. Two tags in the head put it there.

<style>
html::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/svg+xml,%3Csvg xmlns…") 50% 50% / cover no-repeat;
}
body::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("data:image/png;base64,iVBORw0K…") 0 0 / 128px 128px;
  image-rendering: pixelated;
}
html[data-grabient-playing]::before {
  background: none;
}
html[data-grabient-playing] body::before {
  background: none;
}

</style>
<script src="https://staging.grabient.com/kYNh-6rw818GUvVJB75wwtTjQcvy.js?style=zen&amp;grain=20" async></script>

The style holds the first frame, so the page paints it at once and waits on no other site: a plain SVG of the field's levels, each a filled path. The script plays the motion on WebGL from that frame. Without WebGL, or for a reader who asks for less motion, the first frame stays. Leave the page's own background off, or set it on html only. The style paints on html::before and body::before, the grain on the second, so the page's own CSS leaves those to it.

In the editor, Copy HTML gives these two tags for any palette. To link a stylesheet instead of pasting the style, <link rel="stylesheet" href="https://staging.grabient.com/kYNh-6rw818GUvVJB75wwtTjQcvy.css?style=zen&amp;grain=20"> paints the same frame, but the page then waits for it before it paints.
